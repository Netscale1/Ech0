# Code of conduct

Ech0 contributors and maintainers are expected to communicate respectfully,
focus criticism on the work, and make participation welcoming regardless of
experience or background.

Harassment, threats, discriminatory language, deliberate disclosure of private
information, and sustained disruption are not acceptable in project spaces.
Maintainers may edit or remove contributions, lock discussions, or restrict
participation when necessary to protect the project and its participants.

Use GitHub's built-in content reporting tools for abusive public content. For a
matter that should first reach the project maintainer, open an issue containing
only a request for private follow-up; do not place sensitive details or personal
information in that public issue.

This policy applies to repository issues, pull requests, discussions, reviews,
and other spaces where someone represents Ech0.
