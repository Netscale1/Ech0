# Ech0 0.2.0

This is the first public Ech0 release. It connects a Windows microphone to a
macOS application over an authenticated and encrypted local-network session.

## Refreshed community build

The downloadable assets were rebuilt from the current `main` branch on
2026-08-19 and replace the files published earlier under the same `v0.2.0`
tag. Existing downloads have different checksums; verify the replacement files
against the checksums now attached to this release.

The refreshed build includes:

- Windows capture through NAudio 3.0.1 and `WasapiCapture`;
- automatic microphone cleanup when capture demand ends;
- privacy-safe, copyable diagnostics on macOS;
- measured connection RTT and audio buffer health metrics;
- updated open-source documentation and third-party notices.

## Audio endpoint

Ech0 now prefers the bundled, input-only **Ech0 Virtual Microphone**. An existing
**BlackHole 2ch** installation is an optional compatibility fallback, not a
startup requirement. BlackHole is changed to 48 kHz only when Ech0 actually
selects it.

## Community-build warning

- The macOS ZIP is ad-hoc signed and **not notarized by Apple**. It supports
  Apple Silicon Macs running macOS 13 or later.
- The Windows ZIP is **not Authenticode-signed** and may trigger SmartScreen.
- Automatic updates are not included in unsigned builds. Download future
  versions manually and verify the published hashes.

These limitations exist because the project does not use paid Apple Developer
Program or Windows code-signing credentials. The source and credential-free
build gates are included so users can reproduce the artifacts themselves.

Read `INSTALL.md` inside the macOS archive before installing its virtual audio
driver. Do not expose TCP port 48484 directly to the public Internet.
